# NovelAI 画图插件 (Nekro Agent)

适用于 [Nekro Agent](https://github.com/KroMiose/nekro-agent) 的 NovelAI 文生图/图生图插件，支持 NAI v3/v4/v4.5/v5 模型。

## ✨ 功能一览

### 🎨 画图

- **文生图** — 支持中文描述，自动翻译为英文 danbooru 标签
- **图生图** — 通过 Sandbox Tool 由 LLM 代理自动调用
- **尺寸控制** — 在描述末尾加 `竖`（832×1216）、`横`（1216×832）、`方`（1024×1024）即可切换
- **多模型支持** — NAI v3 / v4 / v4.5 / v5，v4+ 自动使用 `v4_prompt` 结构

### 🎭 预设系统

支持 **人物预设** 和 **风格预设** 两种类型，在画图描述中直接写预设名称即可自动识别和展开：

```
/画图 椿，花田，奔跑，横           ← 自动识别人物预设「椿」
/画图 @椿 #风格052 花田            ← 也支持 @/# 显式语法
/画图 人物=椿 风格=风格052 花田     ← 或 key=value 语法
```

**匹配规则：**
- 按预设名长度从长到短匹配，避免短名误匹配
- 检查前后是否为分隔符（逗号、空格、句首/句尾），防止子串误触发
- 例如：预设「椿」不会匹配「椿花绽放」，但会匹配「椿，花田」

仓库根目录附带 **`presets.json`**，内含 **1062 个人物预设 + 60 条画风预设**（人物以二次元游戏角色为主：明日方舟、原神、崩坏：星穹铁道、鸣潮、蔚蓝档案、绝区零、崩坏3 等），复制到插件数据目录 `plugin_data/luoxi.novelai/presets.json` 即可使用，也可以在此基础上增删；格式见下文「导入预设」。

### 🌐 智能分段翻译

与传统的"整体翻译"不同，本插件采用 **智能分段翻译**：

1. 预设展开后，按逗号将 prompt 分割成多个片段
2. 逐段检测：纯英文片段（如已展开的预设标签）**原样保留**
3. 只翻译含中文的片段（如「麦田」「奔跑」）
4. 多个中文片段通过 `asyncio.gather` **并发翻译**

**为什么这样做？** 传统整体翻译会把预设展开后的英文标签（如 `hyacine_(honkai:_star_rail)`）也送给 LLM 重新翻译，导致角色标签被修改、重排或丢失。分段翻译完美避免了这个问题。

### 🔄 重画

使用 `/重画` 命令用上一次的参数重新生成（不同随机种子），也可以追加新描述：

```
/画图 椿，花田，横       ← 第一次画
/重画                    ← 同参数重画一张
/重画 奔跑              ← 在原始描述前追加「奔跑」再画
```

每个会话（群/私聊）独立记录上一次的画图参数。

### 🎴 来点（换人物）

引用/回复一张图片，用 `/来点 <人物预设名>` 即可保留原图构图，把人物换成指定预设（基于图生图）：

```
/来点 椿                  ← 引用一张图 + 换人物「椿」
/来点 椿 站在雨里          ← 也可以追加补充描述
```

换人物的图生图强度/噪声可在插件配置里调整（「来点-图生图强度」「来点-图生图噪声」）。

### 📊 元数据提取

回复一张 NovelAI 生成的图片，使用 `/看参数` 提取生成参数：

- **3 层解析**：PNG tEXt/iTXt 文本块 → stealth pnginfo 隐写（alpha 通道 LSB）→ 无数据则提示
- **提取内容**：正面提示词、负面提示词、steps / scale / sampler / seed / 尺寸 / 模型等

### 🚫 画图黑名单

管理员可以把某个 QQ 号或群加入黑名单，被拉黑的人/群将无法使用本插件画图：

```
/拉黑 123456789 备注可选      ← 拉黑指定 QQ 号或群号
/拉黑                        ← 不带号码 = 拉黑当前群（私聊则为当前用户）
/解除拉黑 123456789          ← 移出黑名单
/黑名单                       ← 查看当前黑名单
```

- 对 **文生图 / 重画 / LLM 沙盒画图工具** 三条入口都生效，命中时直接拒绝，不会消耗 API 次数
- 列表存在插件配置「画图黑名单」里，也可以直接在管理面板编辑（每行一个号码或群号，行内 `#` 之后为注释，号码后可跟备注）：

```
123456789 水群常客
987654321  # 测试群
```

### 🖥️ WebUI 预设管理

插件内嵌了一个暗色主题的预设管理页面，通过 Nekro Agent 的插件路由访问：

**路径：** `http://你的服务器:端口/plugins/luoxi.novelai/`

**功能：**
- 标签页切换人物预设 / 风格预设
- 表单添加新预设（名称 + 提示词）
- 列表展示所有预设，显示名称和对应标签
- 点击「编辑」回填表单修改，点击「删除」移除
- 实时生效，保存后立即可在画图指令中引用

### 🔑 多 Token 轮切

插件配置页的**第一项就是 `NovelAI API Token（必填）`**——不填这个后续所有画图都会失败。填 NovelAI 官方或中转站的密钥（形如 `sk-...` / `pst-...`）。

多个 Token 用英文逗号分隔，遇到 401/402/429 错误时自动轮切到下一个 Token 重试，提高可用性。

### 🤖 Sandbox Tool

插件向 Nekro Agent 的 LLM 沙盒暴露了两个工具函数：

- **NovelAI 文生图** — `novelai_generate(prompt, size, negative_prompt, model, send_to_chat)`
- **NovelAI 图生图** — `novelai_img2img(image_path, prompt, size, strength, noise, ...)`

LLM 可以在对话中根据用户意图自动调用这些工具画图，无需用户手动输入命令。

> **想让 LLM 随时能画图？** 本插件声明了休眠摘要（sleep_brief），属于「可休眠插件」：休眠状态下沙盒工具不进入提示词，LLM 只看得到一句能力摘要，需要先调用 `activate_plugin` 才会激活。
> 若希望它常驻、随时按自然语言画图，请在 WebUI 的插件管理中将本插件的**激活策略设为「禁止休眠」**（`forbid_sleep`）。

## 🔌 第三方中转站

插件支持两类 API 接口，用配置项「接口模式」切换：

| 模式 | 请求地址 | 说明 |
|------|----------|------|
| `novelai`（默认） | `{API 反代地址}/ai/generate-image` | NovelAI 原生格式，步数 / 采样器 / 负面词 / 图生图全部生效 |
| `openai` | `{API 反代地址}/v1/images/generations` | OpenAI 兼容格式，适合只暴露 `/v1` 的中转站；参数是否生效取决于中转站，且**不支持图生图** |

部分中转站把同一模型拆成带后缀的名字（例如 `nai-diffusion-5-full@浅夜`、`nai-diffusion-5-full@岸`）。
这类名字直接填进「模型名覆盖」即可，它会优先于下拉选择的「模型」。

> 实测（akiyo 中转）：OpenAI 兼容模式只采纳尺寸，步数 / 权重 / 采样器 / seed / 负面词由中转站固定；`/重画`、`/来点` 会提示不支持。

## ⚙️ 配置项

在 Nekro Agent 管理面板 → 插件配置中设置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| **API Token（必填）** | **配置页第一项。**填 NovelAI 官方 / 中转站密钥（`sk-...` / `pst-...`），多个用英文逗号分隔，遇 401/402/429 自动轮切 | — |
| API 反代地址 | 替换官方 API 地址，留空使用官方 | — |
| HTTP 代理 | HTTP/SOCKS5 代理地址 | — |
| 模型 | 默认使用的 NAI 模型 | `nai-diffusion-4-5-full` |
| 模型名覆盖 | 留空则用下拉选择的模型；填写后优先，可填中转站带后缀的模型名（如 `nai-diffusion-5-full@浅夜`） | — |
| 接口模式 | `novelai` = 原生 NAI 接口（`/ai/generate-image`）；`openai` = OpenAI 兼容图像接口（`/v1/images/generations`），适合只提供 OpenAI 格式的中转站 | `novelai` |
| 分辨率 | 默认图片分辨率 | `832x1216` |
| 步数 | 采样步数 (1-50) | `28` |
| 权重 | CFG Scale 引导权重 (1-20) | `7` |
| 引导缩放 | CFG Rescale (0.0-1.0) | `0.0` |
| 采样器 | 默认采样器 | `k_euler` |
| 负面提示词 | 全局负面提示词 | — |
| 图生图强度 | img2img 强度 (0.1-0.9) | `0.5` |
| 图生图噪声 | img2img 噪声 (0.0-1.0) | `0.2` |
| R18 开关 | 开启后允许 NSFW 内容 | `关闭` |
| 翻译模型 | 中文→英文标签翻译的聊天模型组 | — |
| 画图黑名单 | 禁止使用画图的 QQ 号/群号，每行一个（也可用 `/拉黑` 等命令管理） | — |
| 来点-图生图强度 | 换人物时的 img2img 强度 (0.1-0.9) | `0.65` |
| 来点-图生图噪声 | 换人物时的 img2img 噪声 (0.0-1.0) | `0.2` |
| 仅限实例标识 | 多个账号共用同一个 Nekro Agent 部署时，只响应来自该实例的消息（一般填该机器人 QQ 号）；留空不限制 | — |

## 📦 安装

```bash
cd /path/to/nekro_agent/plugins/packages/
git clone https://github.com/luoxiQAQ/nekro-plugin-novelai.git nekro_plugin_novelai
```

重启 Nekro Agent，打开管理面板 → 插件配置，**第一项「NovelAI API Token（必填）」填上密钥**即可使用。

### 导入预设

仓库根目录的 `presets.json` 就是给直接使用的：含 1062 个人物预设 + 60 条画风预设。市场安装的插件目录是 `plugins/packages/novelai`（手动 clone 则是 `nekro_plugin_novelai`），复制到插件数据目录：

```bash
cp /path/to/nekro_agent/plugins/packages/novelai/presets.json \
   /path/to/nekro_agent/plugin_data/luoxi.novelai/presets.json

# 文件不存在时新建即可
/path/to/nekro_agent/plugin_data/luoxi.novelai/presets.json
```

想自己从头准备或继续扩充，按下面的结构编辑即可。

文件结构非常简单，`characters` 是人物预设、`styles` 是画风预设，值填英文标签串即可：

```json
{
  "characters": {
    "风堇": "masterpiece, best quality, very aesthetic, 1girl, solo, hyacine (honkai: star rail)"
  },
  "styles": {
    "风格001": "artist:akakura"
  }
}
```

也可以启动后通过 WebUI 的「导入」按钮直接上传 JSON 文件，无需手动改文件。

或通过 WebUI / 命令逐个添加。
